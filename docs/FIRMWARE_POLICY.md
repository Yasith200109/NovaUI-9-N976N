# Firmware and proprietary component policy

This is a public source repository. Do not commit:
- Samsung stock firmware archives or extracted proprietary payloads.
- Vendor/modem binaries or proprietary libraries unless redistribution is explicitly authorized.
- Boot/recovery images copied from firmware packages.
- Paid/copyrighted applications, private signing keys, or personal backups.

For every external component, record its source, version, license, redistribution permission, and checksum where appropriate. A component being downloadable does not mean it is redistributable. Do not add a project license until code provenance and upstream license obligations are reviewed.
