# Installation policy

**There is currently no installable NovaUI build. Do not attempt to flash this repository.**

A future release must include:
- Explicit SM-N976N compatibility statement.
- Verified firmware and bootloader prerequisites.
- Checksums and provenance for every artifact.
- Tested recovery and rollback instructions.
- Known issues and a device-specific test report.

Never flash packages intended for SM-N975F, SM-N976B, or other variants unless exact SM-N976N support is explicitly confirmed and tested. Back up personal data and critical device information before any future experimental installation.
