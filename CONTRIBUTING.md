# Contributing

Thanks for helping with NovaUI 9 N976N.

## Before opening a change
- Explain the problem and exact target model (SM-N976N).
- Link the upstream source and identify its license.
- Include reproducible steps and logs with personal data removed.
- Separate verified facts from assumptions.

## Safety requirements
- Never submit IMEI/EFS data, account tokens, private keys, personal backups, or proprietary firmware payloads.
- Do not add files copied from another Note10 variant without proving compatibility.
- Do not submit scripts that flash, erase, repartition, unlock, or modify modem/EFS partitions.
- Keep experimental work clearly labelled.

## Changes
Use focused pull requests. Update device support and testing documents when compatibility claims change. No claim of working hardware support should be made without a test record from SM-N976N.
